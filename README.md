# DistilBERT Sentiment Analysis

## Project Overview

This project focuses on sentiment analysis of movie reviews using the DistilBERT
Transformer model. The model is fine-tuned on the IMDB Movie Review Dataset to
classify reviews as either positive or negative.

## Objective

The main objective of this project is to develop a Natural Language Processing
(NLP) model capable of understanding the sentiment expressed in text and
classifying it into positive or negative categories.

## Model

- **Model:** DistilBERT
- **Task:** Binary Sentiment Classification
- **Dataset:** IMDB Movie Review Dataset
- **Framework:** Hugging Face Transformers
- **Language:** Python
